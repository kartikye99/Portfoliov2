# Kartikye Saini - Premium Developer Portfolio

A modern, high-performance, and creative developer portfolio engineered for **Kartikye Saini** (Full-Stack Developer, LeetCode 400+, Roomify AI 3D Architect, Real-time WebSockets Specialist).

## 🚀 Key Features

- **Interactive Constellation Canvas**: Smooth 60 FPS HTML5 canvas starfield that reacts to mouse position and constellations.
- **Dynamic Terminal CLI (`kartikye@production-node`)**: Full-featured interactive terminal with commands (`help`, `about`, `skills`, `projects`, `stats`, `sudo hire`, `clear`). Press \` or `~` to trigger.
- **Live 3D & AI Room Simulator (`Roomify`)**: Interactive 2D floorplan blueprint switcher, 3D architectural isometric render, theme presets (Scandinavian, Cyberpunk, Minimalist), and dynamic lighting controls.
- **Real-Time WebSocket Simulator (`Chat App`)**: Interactive messaging sandbox with simulated active sessions, realistic typing feedback, and instant WebSocket bot replies.
- **Interactive DSA Algorithmic Execution Sandbox**: Step-by-step visualizer for Bubble Sort and Two-Pointer Target Sum in C++ with real-time asymptotic complexity tracing.
- **Interactive Audio Feedback System**: Web Audio API micro-synthesizer for tactile futuristic UI sound effects (zero external audio files needed; muteable toggle included).
- **Printable Resume Engine**: High-fidelity, print-ready digital resume with one-click PDF printing / download.
- **Direct Dispatch Contact**: 1-click clipboard copy for email (`kartikyesaini@gmail.com`) and phone (`+91 7906913880`), validation, and celebratory confetti effects.

- **Effects**: HTML5 Canvas, Web Audio API, Canvas Confetti

## 💻 Quick Start

### 1. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Build for Production
```bash
npm run build
```
Generates optimized static assets in the `/dist` directory.

### 3. Preview Production Build
```bash
npm run preview
```

## 🌐 Deployment

You can deploy this portfolio instantly to:
- **Vercel**: Import repository and deploy with Vite preset.
- **GitHub Pages**: Build and push `/dist` branch or configure GitHub Actions.
- **Netlify**: Connect repository and set build command to `npm run build` with publish directory `dist`.
